# Making Memory Management Easy in C/++


Jacob Bell joins us this month talking about memory management in C/C++

Covers null pointers, uninitialized memory, memory leaks, and dangling pointers. In each section we'll compile a small example and run it with debugging tools to locate the problem, then talk about how to prevent the problem in the first place.
